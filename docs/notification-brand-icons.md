# Notification brand icon sources

Brolly vendors monochrome notification-service symbols locally and renders them
in each service's published brand color. No icon request is made at runtime.

| Service | Local file | Brand guidance |
| --- | --- | --- |
| Discord | `public/brand-icons/discord.svg` | <https://discord.com/branding> |
| Slack | `public/brand-icons/slack.svg` | <https://slack.com/media-kit> |
| Twilio | `public/brand-icons/twilio.svg` | <https://www.twilio.com/company/brand> |

The Discord path was retrieved from Simple Icons v16; Slack and Twilio were
retrieved from v15 because those symbols are no longer distributed in v16.
Each icon's metadata points to the corresponding vendor brand source.
Retrieved 2026-08-10.
